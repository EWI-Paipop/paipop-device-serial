# Paipop 设备序列号查询

纯静态浏览器工具，用于：

- 由正式 SN 生成匿名设备序列号；
- 从含 `sn` 列的本地 CSV 中反查正式 SN。

## 安全边界

- 产品密钥不写入仓库、页面源码或浏览器持久化存储；
- CSV 和密钥只在当前页面内存中处理；
- CSP 禁止页面发起网络连接；
- 页面不使用第三方脚本、字体、分析或 CDN。

设备端和网页端共同实现 `CT1` 算法：HMAC-SHA256、前 80 bit、Crockford Base32 和 CRC-5/USB 校验位。

## 本地验证

```sh
npm test
```

本地预览需使用静态 HTTP 服务，因为 Web Crypto 在安全上下文中工作。发布目标为 GitHub Pages，仓库中不得加入产品密钥或真实设备 SN。
